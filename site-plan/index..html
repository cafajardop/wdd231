DailyFit

Site Plan

1. Site Name

DailyFit

Reason: The name reflects the goal of promoting simple daily fitness routines and healthy habits that are easy to maintain.

Optional domain idea (not required): dailyfit.life

2. Site Purpose

The purpose of this website is to provide information about fitness and healthy habits that help users improve their daily lifestyle. The site will offer simple fitness routines, healthy habit tips, and practical ideas that users can apply in their everyday lives.

The website will include at least three main pages:

  • Home: introduces the importance of healthy habits and staying active.
  • Healthy Habits: focuses on walking, stretching, hydration, and basic exercises.
  • Habit Toolkit: provides simple habit-tracking ideas using basic JavaScript interactions (e.g., checklists/buttons).

3. Scenarios

These questions represent what target users might ask when visiting the site:

  • What simple daily exercises can I do at home without equipment?
  • How can I build healthy habits if I have a busy schedule?
  • What small routines can help improve my energy during the day?

4. Color Scheme

The site plan uses the selected colors below (applied in this document via CSS).

Primary Green: #2E7D32

Used for headings, links, buttons, and accents.

Background Light Gray: #F4F4F4

Used for page background and section spacing.

Text Charcoal: #333333

Used for body text and general readability.

5. Typography

The site uses two font families (loaded from Google Fonts and applied in this document):

  • Poppins — used for headings (h1–h3).
  • Open Sans — used for body text and UI text.

Heading Example — Build Better Habits

Body Example — Small steps every day add up. This site focuses on simple routines and practical habit tips.

Additional Notes (Reason for Choosing This Subject)

I chose this subject because fitness and healthy habits are important for overall well-being and are relevant to many people. This topic allows me to create meaningful content while practicing essential web development skills such as page structure, responsive design, and simple interactivity.

Additionally, this subject is flexible and allows future improvements, such as adding more interactive features or expanding the content as I learn more web development techniques.
